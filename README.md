# Todo List

A simple and responsive Todo List web application built using **HTML, CSS, and JavaScript**.

Tasks are saved using **Local Storage**, so your todos remain available even after refreshing or reopening the browser.

## Features

* Add new tasks
* Mark tasks as completed
* Delete tasks
* Tasks persist using Local Storage
* Simple and clean user interface
* Built without any external libraries or frameworks

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Local Storage

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start adding your tasks.
